# 简历分析系统

当前仓库已经完成一期开发前的准备工作，目标是先打通 MVP 主链路：

1. 用户注册与登录
2. 简历上传与解析
3. 岗位描述录入与解析
4. AI 分析任务创建
5. 分析报告查看与历史记录

- `简历分析系统项目需求文档.md`：产品范围、验收标准、MVP 建议

## 当前目录结构

```text
backend/               FastAPI 后端骨架
frontend/              Vue 3 前端骨架
storage/resumes/       简历上传文件目录
deploy/                部署脚本与 Nginx 预留目录
docker/                容器相关辅助目录
docs/                  项目启动准备文档
data/                  本地数据目录预留
logs/                  日志目录预留
backups/               备份目录预留
```

## 本地启动

1. 检查 Docker 可用
2. 按需修改 `.env.dev`
3. 运行 `docker compose --env-file .env.dev up --build`
4. 打开 `http://localhost:8000/health` 与 `http://localhost:8000/docs`
