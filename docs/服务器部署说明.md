# 服务器部署说明

## 1. 部署目标

本项目推荐采用以下生产部署结构：

- `frontend` 容器：构建 Vue 前端并使用 Nginx 提供静态资源
- `backend` 容器：运行 FastAPI 服务
- `db` 容器：运行 PostgreSQL

生产环境中，推荐只暴露前端 Nginx 端口，对外统一访问：

- `https://your-domain.com`
- `https://your-domain.com/api/...`

## 3. 首次部署前准备

在服务器上拉取项目后：

1. 复制生产环境变量模板
2. 修改为真实配置

```powershell
Copy-Item .env.prod.example .env.prod
```

重点修改这些项：

- `APP_SECRET_KEY`
- `JWT_SECRET_KEY`
- `POSTGRES_PASSWORD`
- `DATABASE_URL`
- `DEEPSEEK_API_KEY`
- `CORS_ORIGINS`
- `ADMIN_PASSWORD`

说明：

- `VITE_API_BASE_URL` 在生产环境建议保持为 `/api`
- 前端通过 Nginx 反向代理后端，因此不需要把前端写死到 `http://localhost:8000`

## 4. 启动生产环境

在项目根目录执行：

```powershell
docker compose --env-file .env.prod -f docker-compose.prod.yml up -d --build
```

## 5. 访问方式

默认情况下：

- 前端访问：`http://服务器IP/`
- 后端 API 通过前端同域代理访问：`http://服务器IP/api/...`

如果你配置了域名和 HTTPS，则推荐使用：

- `https://your-domain.com`

## 6. 停止服务

```powershell
docker compose --env-file .env.prod -f docker-compose.prod.yml down
```

## 7. 本地开发与生产环境区别

本项目建议采用如下策略：

- 本地开发：前端使用宿主机 `npm run dev`
- 生产部署：前端使用 Docker + Nginx

这样既能保持本地开发体验，也能让服务器部署保持一致、稳定和易迁移。
