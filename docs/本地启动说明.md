# 本地启动说明

## 1. 环境准备

- 已安装 Docker Desktop
- 已安装 Node.js
- 已安装 npm

项目根目录：

```powershell
D:\Codex\Codex_resume
```

## 2. 检查配置

先确认根目录下的 `.env.dev` 配置正确：

- `DEEPSEEK_API_KEY` 已填写
- `POSTGRES_PASSWORD` 与 `DATABASE_URL` 中的密码一致
- 当前 PostgreSQL 映射端口为 `55432`

## 3. 启动后端和数据库

在项目根目录执行：

```powershell
docker compose --env-file .env.dev up -d --build
```

启动完成后，可用下面两个地址检查后端健康状态：

- `http://127.0.0.1:8000/api/health`
- `http://127.0.0.1:8000/health`

## 4. 启动前端

新开一个终端，执行：

```powershell
cd D:\Codex\Codex_resume\frontend
npm install
npm run dev
```

启动后访问：

- 用户端：`http://127.0.0.1:5173`
- 管理端：`http://127.0.0.1:5173/admin`

说明：

- 前端已固定使用 `5173`
- 如果 `5173` 被其他程序占用，Vite 会直接报错，不会再自动跳到 `5174`
- 遇到这种情况，请先释放 `5173` 端口后再重新执行 `npm run dev`

如果使用 Navicat，连接信息如下：

- Host：`127.0.0.1`

- Database：`resume_analyzer`

## 7. 停止服务

在项目根目录执行：

```powershell
docker compose --env-file .env.dev down
```

前端开发服务可在对应终端按 `Ctrl + C` 停止。
